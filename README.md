# Nuvora Brand Assets

This repository is the source library for Nuvora's official logo and brand image files.

## Logo files

| File | Intended use |
|---|---|
| `For Light.png` | Light-background logo |
| `For Dark Logo.png` | Dark-background logo |
| `For Light Mode.png` | Light-mode brand artwork |
| `For Dark Mode.png` | Dark-mode brand artwork |
| `nuvora-favicon.png` | Browser favicon and compact brand mark |

## Website integration

The production website repository is [Nuvora](https://github.com/indramaulanacode/Nuvora).

The website serves optimized static paths from its `public/brand/` directory:

- `/brand/nuvora-light-logo.png`
- `/brand/nuvora-dark-logo.png`
- `/brand/nuvora-light-mode.png`
- `/brand/nuvora-dark-mode.png`
- `/brand/nuvora-favicon.png`

Keep this repository as the central source for original brand assets. Copy approved updates into the website repository's `public/brand/` directory when changing the live site.
